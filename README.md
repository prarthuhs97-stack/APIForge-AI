# APIForge AI

AI-powered API documentation generator that analyzes API source code and creates context-aware documentation.

## Features

- 🔍 API endpoint detection
- 🧩 Automatic parameter extraction
- 🧠 Context-aware API analysis
- 🔐 Security issue detection
- 📚 Automatic API documentation
- 📊 Documentation quality scoring
- 📄 OpenAPI and Markdown export
- 🔄 API change detection support

## How It Works

```text
API Source Code
      ↓
API Parser
      ↓
Security Scanner
      ↓
Context Analyzer
      ↓
Documentation Generator
      ↓
Quality Checker
      ↓
Context-Aware API Documentation
